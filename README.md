# Stellar burgers – космическая бургерная 

[Demo](https://yaylnt.github.io/stellar-burgers/)

Приложение, которое поможет любой форме жизни где-то на краю Вселенной заказать тот бургер, который она хочет. В приложении есть конструктор бургера, лента заказов, личный кабинет, функционал создания заказа, регистрации и авторизации пользователя, а также смены учётных данных.

## Установка и запуск
Для установки и запуска проекта необходимо выполнить команды

```
npm install
npm run dev
```

## Сборка

```
npm run build
```

## Мой вклад в проект:

- Реализовала маршрутизацию на React Router, включая защищённые маршруты.
- Настроила глобальное управление состоянием приложения через Redux.
- Покрыла юнит-тестами на Jest Redux-редьюсеры и асинхронные состояния, достигнув 92,92%
покрытия тестируемой логики.
- Реализовала интеграционные тесты ключевых сценариев конструктора на Playwright,
включая оформление заказа. Использовала HAR-моки API и тестовую авторизацию через
cookies и localStorage.
- Настроила CI/CD.
